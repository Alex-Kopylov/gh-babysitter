# cli — целевой пользователь и модель подписок

## Целевой пользователь — AI-агент

Целевой пользователь — **AI-агент** (Claude Code, Codex CLI и т.п.): по запросу
«babysit this PR» агент запускает `listen`, блокируется в ожидании результата и
выходит. Человек в терминале работает так же, просто руками. Отсюда два
следствия: эфемерная модель подписок и exit-условия
([spec.md](spec.md)).

## Почему подписки эфемерны

- Основной сценарий агентный: подписка нужна на время задачи — «понянчить
  PR #24» — и мертва после мёржа. Персистентный список таких подписок копил бы
  мусор из закрытых PR и issues.
- «Память между сессиями» — не-цель: агент каждый раз собирает команду заново
  из контекста своей задачи. Человеку со стоячим набором подписок хватит alias
  или скрипта — это забота пользователя, а не инструмента.
- Ноль состояния = систему невозможно привести в несогласованное: и клиент, и
  сервер после рестарта чисты по построению, всё восстанавливается самим фактом
  переподключения.
